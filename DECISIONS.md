| 2026-11-25 | Host development in the public Ahmed41022/Duet repository. | New public repository, new private repository, existing repository | Ahmed selected the new public repository for pull requests and Windows/Linux CI. | M0 |
| 2026-11-25 | Build the Vite client into the Python server package before distribution. | Include compiled assets in the wheel, or require Node.js on each PC | The installed PC app can serve the phone UI offline. Only developers and CI need Node.js. | M0 |
| 2026-11-25 | Use a TOML settings file with explicit loading and in-memory defaults. | TOML, JSON, or environment variables alone | Python 3.11 reads TOML with its standard library. Loading defaults leaves the filesystem untouched. | M0 |
| 2026-11-25 | Use aiohttp with an explicit RFC 1918 bind address and check the origin of browser API requests. | aiohttp or an ASGI stack | One server handles streaming, pairing and live events, with no external services. | M1 |
| 2026-11-25 | Rotate a single-use QR/PIN after pairing or ten minutes. Sessions last eight hours. | Independent or shared offers, fixed or sliding expiry | Either credential consumes the offer. A fixed session lifetime and PC-side revocation bound access. | M1 |
| 2026-11-25 | Track chunks per paired session. Support idempotent creation, completion and cancellation. | In-memory or persistent manifests | A disconnected phone can recover its upload during the active server session, including when it lost the response that assigned the upload ID. | M2 |
| 2026-11-25 | Publish verified staging files using Windows non-replacing rename or POSIX hard links. | Replace, non-replacing publication, or a separate copy | Concurrent completions keep distinct filenames and partial content stays hidden from the final path. Linux Received volumes must support hard links. | M2 |
| 2026-11-25 | Hash files incrementally in the phone browser and persist upload identifiers for resume. | Secure-context-only Web Crypto, buffering the whole file, or incremental JavaScript SHA-256 | Plain LAN HTTP and large files both work. After reload, selecting the original file lets the client verify its digest and send only missing chunks. | M3 |
| 2026-11-25 | Keep the latest 100 shared text messages in memory for the current server run. | Save all message contents to disk or share them for the current run | Both directions are available without retaining clipboard-like text after shutdown. | M3 |
| 2026-11-25 | Share a SQLite outbox between the CLI, desktop, and running server. | Local IPC or a persistent database | Files can be offered before starting the server. The running server notices changes from other processes. | M4 |
| 2026-11-25 | Stream a deterministic ZIP64 representation of folder offers. | Prebuild a temporary archive or stream it on demand | Downloads support byte ranges without storing a second full copy of the folder. Resuming a folder download can reread earlier source bytes. | M4 |
| 2026-11-25 | Run the desktop listener on its own asyncio thread and persist completed transfer metadata in SQLite. | Blocking calls from Qt or a separate server process | The GUI can keep its controls responsive while using the same authenticated server as the CLI. | M5 runtime |
| 2026-11-25 | Publish local device status without credentials and validate server process identity and session expiry. | Additional management socket or local status files | The devices command can inspect running listeners without starting a server or requiring a phone cookie. | M5 runtime |
| 2026-11-25 | Package Qt as the optional desktop extra and use the same transfer server as the CLI. | Require Qt for every installation, or isolate the GUI dependencies | The CLI and core stay usable in headless environments. CI installs the extra and exercises the window offscreen. | M5 desktop |
| 2026-11-25 | Release the window and flush deferred Qt deletions before shutting down the application. | Rely on interpreter teardown or explicitly close Qt on its owning thread | Windows could crash after all assertions passed. Subprocess tests check both window close and application quit through process exit. | M5 desktop |
| 2026-11-25 | Rank assigned private addresses using adapter type and available network profile information. | First private address, a manually configured address, or ranked discovery | The QR code should point to a reachable hotspot or Wi-Fi interface even with VPNs and virtual adapters active. A manual selection is still available. | M6 |
| 2026-11-25 | Stop on address loss or after an interval without meaningful activity, while allowing active transfers to finish. | Restart automatically on a different interface, or stop until the PC user starts again | A change of network requires a deliberate new session. Read-only polling and SSE keepalives do not keep the server on indefinitely. | M6 |
| 2026-11-26 | Search all stored transfer filenames and display the newest 100 matches. Notify on newly recorded completed receives. | Filter only the recent view or scan all history, notify from snapshots or completion events | Older filenames stay searchable. An insert event avoids repeating notifications when reopening Duet or polling the UI. | M7 desktop |
